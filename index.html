📚 명령형 문법 정리
인칭 긍정 명령 부정 명령
yo 존재하지 않음
tú 직설법 현재 3인칭 단수
habla, come, vive		 접속법 현재 2인칭 단수
no hables, no comas
usted 접속법 현재 3인칭 단수
hable, coma, viva		 접속법 현재 3인칭 단수
no hable, no coma
nosotros 접속법 현재 1인칭 복수

no hablemos, no comamos
vosotros 동사원형에서 r → d

ustedes 접속법 현재 3인칭 복수

no hablen, no coman
📌 핵심 정리
• tú 긍정 — 직설법 현재 3인칭 단수 (él/ella형과 동일)
• tú 부정 — 접속법 현재 2인칭 단수 앞에 no
• usted / ustedes — 긍정·부정 모두 접속법 사용
• nosotros — 긍정·부정 모두 접속법 1인칭 복수 사용
• vosotros 긍정 — 동사원형의 -r을 떼고 -d를 붙임
• vosotros 부정 — 접속법 현재 2인칭 복수 앞에 no
※ 과테말라 등 중남미에서는 vosotros 대신 ustedes를 일상적으로 사용합니다.
※ 앱의 명령형 탭에는 긍정 명령만 표시됩니다. 부정 명령은 접속법 탭 + no를 활용하세요.
📚 접속법 현재 만드는 법
📌 기본 규칙
직설법 현재 1인칭 단수(yo형)에서 어미를 떼고, 반대 모음 어미를 붙입니다.
-ar 동사 → yo형 어간 + e 계열 어미
-er/-ir 동사 → yo형 어간 + a 계열 어미
-ar 동사 (예: hablar → yo hablo → habl-)
인칭 단수 복수
1인칭 habl-e habl-emos
2인칭 habl-es habl-éis
3인칭 habl-e habl-en
-er / -ir 동사 (예: comer → yo como → com-)
인칭 단수 복수
1인칭 com-a com-amos
2인칭 com-as com-áis
3인칭 com-a com-an
⚠️ 주의사항
• 불규칙 동사는 yo형 어간이 불규칙이므로 접속법도 불규칙
  예: tener → yo tengo → tenga, tengas...
      hacer → yo hago → haga, hagas...
• ser, estar, ir, haber, saber는 완전 불규칙
  예: ser → sea / estar → esté / ir → vaya
📚 불완료 과거 만드는 법
📌 언제 쓰나요?
• 과거의 반복적인 습관 — "어렸을 때 매일 운동했다"
• 과거의 진행 중인 상태·배경 — "비가 오고 있었다"
• 과거의 감정·상태 묘사 — "그 때 행복했다"
→ 단순과거(완료된 사건)와 함께 자주 쓰임
-ar 동사 (예: hablar → habl-)
인칭 단수 복수
1인칭 habl-aba habl-ábamos
2인칭 habl-abas habl-abais
3인칭 habl-aba habl-aban
-er / -ir 동사 (예: comer → com-)
인칭 단수 복수
1인칭 com-ía com-íamos
2인칭 com-ías com-íais
3인칭 com-ía com-ían
⚠️ 주의사항
• 불완료 과거는 불규칙 동사가 단 3개뿐이에요
  ser → era, eras, era, éramos, erais, eran
  ir → iba, ibas, iba, íbamos, ibais, iban
  ver → veía, veías, veía, veíamos, veíais, veían
• 나머지 모든 동사는 규칙 변화를 따릅니다
📚 단순과거 만드는 법
📌 언제 쓰나요?
• 과거의 완료된 특정 사건·행동 — "어제 보고서를 제출했다"
• 명확한 시점이 있는 과거 — ayer(어제), la semana pasada(지난주), hace X años(X년 전)
→ 불완료과거(습관·배경)와 구별해서 사용
-ar 동사 (예: hablar → habl-)
인칭 단수 복수
1인칭 habl-é habl-amos
2인칭 habl-aste habl-asteis
3인칭 habl-ó habl-aron
-er / -ir 동사 (예: comer → com-)
인칭 단수 복수
1인칭 com-í com-imos
2인칭 com-iste com-isteis
3인칭 com-ió com-ieron
⚠️ 주요 불규칙 동사
• ser / ir → fui, fuiste, fue, fuimos, fuisteis, fueron (둘이 동일)
• tener → tuve, tuviste, tuvo, tuvimos, tuvisteis, tuvieron
• hacer → hice, hiciste, hizo, hicimos, hicisteis, hicieron
• estar → estuve, estuviste, estuvo, estuvimos, estuvisteis, estuvieron
• poder → pude, pudiste, pudo, pudimos, pudisteis, pudieron
• decir → dije, dijiste, dijo, dijimos, dijisteis, dijeron
📚 과거완료 만드는 법
📌 언제 쓰나요?
• 현재와 연결된 과거 경험·결과 — "이미 먹었어요", "그 영화 본 적 있어요"
• haber 현재형 + 과거분사로 구성
→ 단순과거(어제 했다)와 달리 현재 시점에서 바라보는 과거
① haber 현재형
인칭 단수 복수
1인칭 he hemos
2인칭 has habéis
3인칭 ha han
② 과거분사 만들기
동사 유형 만드는 법 예시
-ar 동사 어간 + -ado hablar → hablado
-er / -ir 동사 어간 + -ido comer → comido
⚠️ 불규칙 과거분사
• hacer → hecho (한)  •  decir → dicho (말한)
• ver → visto (본)  •  volver → vuelto (돌아온)
• poner → puesto (놓은)  •  abrir → abierto (열린)
• escribir → escrito (쓴)  •  romper → roto (깨진)
